VODHit closed beta

A local-first workspace for creators who want to explore their YouTube Studio exports, track video work, and keep notes in one place. This is experimental software: some analytics are incomplete and should not be used for financial or business decisions.

Installer status: not available yet

A verified, Developer ID-signed and Apple-notarized DMG has not been published. There is no download link on this page until release checks pass. Do not install unofficial copies or disable macOS security protections.

When the private beta is ready, selected participants will receive their own access instructions and the release version/checksum. A public URL alone is not access control.

What you need

  • Mac with Apple Silicon (M-series), macOS 12 or later.
  • A local folder for one VODHit data profile.
  • Exports from your own YouTube Studio (CSV, TSV or ZIP).
  • Time to report issues, with private data removed from screenshots.

Intel Macs and earlier macOS versions are not verified.

What to expect

  • No YouTube account sign-in or automatic Google API synchronization.
  • One YouTube channel per local beta profile.
  • Manual Studio imports, notes, charts, filters and backups.
  • Analytics coverage limitations and no automatic updates.

See the documented limitations before interpreting any statistics.

Installing the beta

Once you receive a verified installer, follow the installation steps. The DMG contains the app and an Applications shortcut. You should not need Terminal, Node.js, or a compiler.

Help improve VODHit

Use the suggested test checklist and bug-report template. Share feedback via the private contact method in your invitation. Do not send passwords, tokens, or raw Studio exports.
